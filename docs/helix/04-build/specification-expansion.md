# Specification expansion — 2026-11-02

## Delivered specification scope

Five target contracts define exposure/projection, neutral asynchronous execution,
GraphQL/Relay behavior, TypeScript build/network/store behavior and bounded ASGI
hosting. Three Draft 2020-12 schemas own configuration/manifest shapes. A neutral
Python protocol stub and an original logical task-board/exposure/SDL/operation
corpus make the desired interfaces inspectable.

Each of the six original features/stories now has a feature-owned solution design,
a story technical design and a story test plan. The original 24 acceptance IDs
are preserved. Story Test Plans own exact planned test/citation/assertion mapping.
Original artifact frontmatter, IDs, links and unknown metadata remain byte-equivalent.

## Observed checks

- All 42 governed HELIX artifacts pass the installed 0.20.0 instance validator,
  with zero blocking findings or warnings. Validation used staged source bytes;
  installation verifies that the copied files match those bytes.
- All three schemas pass Draft 2020-12 schema checks. Positive exposure/host and
  synthetic manifest shapes validate. Ten negative schema cases reject unknown
  fields, reserved introspection names, widened page limits and unsafe file paths.
- The logical task-board source passes the inspected current UMF core 0.10 JSON
  Schema. Reference/Key/member mappings and unique logical identities are checked.
- GraphQL-core 3.2.13 validates the example SDL and four standard executable
  documents. Relay authoring documents parse and correctly fail uncompiled standard
  server validation because their compiler directives require Relay processing.
- The protocol stub parses as Python syntax. No installed port implementation or
  structural type-conformance claim follows from that check.
- Local links, artifact references, schema sources and the complete 24-criterion
  story-plan mapping are checked. Source digests bind retained evidence to content.

[Machine checks](evidence/specification-checks.json) and
[instance results](evidence/specification-instance-results.json) retain versions,
source digests and validator results. Cached read-only dependencies were used;
no product dependencies were installed and no application framework/server ran.

## Qualification limits and next technical decisions

These are target contracts, not implemented public interfaces. No native request
snapshot, edge cursor, host confirmation/recovery, installed cohort, Relay compiler,
browser Store, Databricks deployment or family-site update is established.
GraphQL-core's syntax/validation result is not GraphQL September 2025 conformance.

S-01–04 must qualify the upstream description and typed key-argument metadata,
dynamic framework construction, native request-consistent batching/paging, Batten
public invocation and Relay public compiler/scalar-validation integration. A failed
spike requires an explicit contract revision, never silent scope reduction.
S-05 independently qualifies Databricks Apps. Exact dependency versions, release
artifact names, license/publisher decisions and production host policy remain
separate release choices; no invented dates or capacity claims were added.

No runtime source, Batten implementation, upstream engine, commit or push was
performed by this specification expansion.
